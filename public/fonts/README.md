# Add your Coolvetica font files here

Coolvetica (by Ray Larabie / Typodermic) is not on Google Fonts and is only
free for personal use — commercial use requires a license from
https://typodermicfonts.com/coolvetica/

Drop your licensed files in this folder using these exact names (or update
the `@font-face` block in `app/globals.css` to match your filenames):

- coolvetica-rg.woff2
- coolvetica-rg.woff   (optional, older-browser fallback)

Until these files are added, headings will gracefully fall back to Manrope
so the site still looks fully designed.
